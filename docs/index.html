Training-free time–frequency transformers on Daubechies wavelets

ssmix2d mixes audio jointly across time and frequency with exact multiscale operators: a separable 2-D Daubechies tight frame over (time, mel), and a cross-scale attention mixer in which every coefficient attends to its siblings, parents and children along both axes. Nothing is trained.

Install

Try it in the browser: live demo on Hugging Face Spaces. The 1-D predecessor is State-Space-Mixer.

Requires Python ≥ 3.9, PyTorch ≥ 2.0, torchaudio, NumPy and mpmath.

Embed audio in three lines

from ssmix2d import AudioEmbedder2D

emb = AudioEmbedder2D()                                # no weights to download
E = emb.embed(waves, sample_rate=44100, length=5.0)    # list of 1-D arrays -> (N, D) numpy

Inputs are resampled to 32 kHz. With length every clip is padded or cut to the same duration, so all embeddings share one dimension. Use the embeddings with any linear model, k-NN or clustering.

Use the 2-D mixer as a layer

import torch
from ssmix2d import CrossScaleMixer2D

X = torch.randn(8, 500, 128)                           # (batch, time, frequency)
mixer = CrossScaleMixer2D(order=4, freq_order=2, window=2, tau=0.1)
Y = mixer(X)                                           # same shape, cross-scale attention on both axes

W, plan = mixer.coefficients(X)                        # (8, S, R, nt, nf): every time scale x every frequency scale
assert torch.allclose(mixer.synthesize(W, plan), X, atol=1e-4)   # exact round trip

What is inside

ObjectRole
AudioEmbedder2DTraining-free audio transformer: log-mel → 2-D cross-scale mixer blocks → pooled scale-space readout.
CrossScaleMixer2DCross-scale attention on the separable 2-D Daubechies tight frame; shift-equivariant in time.
ScaleSpaceMixerFFT-batched 1-D Daubechies tight frame for any length: the building block of each axis.
daubechiesDaubechies filters of any order, built from scratch by spectral factorisation.
