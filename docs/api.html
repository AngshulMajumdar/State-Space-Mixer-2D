API reference

Everything below is importable from ssmix2d. All modules are parameter-free torch.nn.Modules that run on CPU or CUDA. CrossScaleMixer2D takes (batch, time, frequency); ScaleSpaceMixer takes (batch, tokens, channels).

class AudioEmbedder2D

ssmix2d.AudioEmbedder2D(depth: int = 2, sample_rate: int = 32000, n_mels: int = 128, order: int = 4, freq_order: int = 2, levels: Optional[int] = None, freq_levels: Optional[int] = None, group: int = 8, window: int = 2, tau: float = 0.1, readout: Sequence[str] = ('bands', 'stats', 'mixed', 'attn', 'env'))

Training-free audio transformer that mixes jointly across time and frequency.

Pipeline:
    log-mel spectrogram (25 ms window, 10 ms hop)  ->  per-clip normalisation
    depth x [ separable Daubechies tight frame over (time, mel)
              -> 2-D cross-scale attention (time and frequency siblings, parents, children)
              -> exact synthesis ]
    readout of every block, pooled over time.

The model has no learnable parameters and needs no training data.

Args:
    depth:        number of mixer blocks.
    sample_rate:  rate the model operates at; `embed` resamples inputs to it.
    n_mels:       mel bands.
    order:        Daubechies order along time (support 2N-1).
    freq_order:   Daubechies order along the mel axis.
    levels:       time levels J_t (None: chosen from the clip length).
    freq_levels:  mel-axis levels J_f (None: chosen from n_mels).
    group:        mel bins per attention token (a divisor of 16).
    window:       sibling half-width k on each axis.
    tau:          attention temperature.
    readout:      subset of ("bands", "stats", "mixed", "attn", "env").

Readout terms (per block unless noted):
    bands  log mean_t |W_{s,r}| before mixing, per time band s, mel band r and mel bin
    stats  mean_t and std_t of the normalised log-mel state (also once after the last block)
    mixed  log mean_t |W'_{s,r}| after mixing
    attn   mean_t attention weight per band, link and mel group
    env    mean log-mel spectrum before normalisation (once, appended last)

Example:
    >>> emb = AudioEmbedder2D()
    >>> E = emb.embed([wave_a, wave_b], sample_rate=44100, length=5.0)   # (2, D) numpy array

Embed one clip, a batch, or a list of clips of any lengths.

Args:
    audio:       1-D waveform, (B, N) array/tensor, or a list of 1-D waveforms (mono, [-1, 1]).
    sample_rate: rate of `audio`; resampled to `self.sample_rate` when different.
    batch_size:  clips per forward pass.

    (B, D) float32 numpy array (rows in input order).

class CrossScaleMixer2D

ssmix2d.CrossScaleMixer2D(order: int = 4, freq_order: int = 2, levels: Optional[int] = None, freq_levels: Optional[int] = None, group: int = 8, window: int = 2, tau: float = 0.1, pad: str = 'reflect')

Parameter-free cross-scale attention on the separable 2-D Daubechies tight frame.

Args:
    order:        Daubechies order along time (support 2*order - 1).
    freq_order:   Daubechies order along frequency.
    levels:       time levels J_t (None: as many as fit the length).
    freq_levels:  frequency levels J_f (None: as many as fit the number of bins).
    group:        frequency bins per token (a divisor of 16).
    window:       half-width k of the sibling neighbourhood on each axis.
    tau:          attention temperature (tau -> 0 is the identity).
    pad:          boundary handling of both frames, "reflect" or "circular".

Input and output: (B, T, F) real tensors.

coefficients(self, X: torch.Tensor)

(B, T, F) -> padded coefficients W (B, S, R, nt, nf) and the plan needed for synthesis.

synthesize(self, W: torch.Tensor, plan: dict) -> torch.Tensor

Padded coefficients (B, S, R, nt, nf) -> (B, T, F) by the tight-frame adjoint (exact inverse).

valid(self, plan: dict)

Slices of the padded grid holding the input's own samples: (time slice, frequency slice).

links(self, S: int, R: int) -> Dict[Tuple[int, int], List[Tuple[int, int, int, int]]]

Key list of every band (s, r): [(s', r', time shift, frequency shift)], self first.

mix(self, W: torch.Tensor) -> torch.Tensor

One synchronous cross-scale attention update of padded coefficients (B, S, R, nt, nf).

Every key is normalised over its own `group` bins after shifting (key norms come from a sliding
window sum of squares), so frequency shifts that are not multiples of `group` are exact.
Attention weights are kept in `last_attention[(s, r)]` as (B, links, nt, groups), or, if `att_crop`
= (t0, t1, g0, g1) is set, as their mean over t0:t1 restricted to groups g0:g1 (B, links, g1 - g0).

forward(self, X: torch.Tensor) -> torch.Tensor

(B, T, F) -> (B, T, F): 2-D analysis, one cross-scale attention update, exact synthesis.

class ScaleSpaceMixer

ssmix2d.ScaleSpaceMixer(order: Optional[int] = 4, support: Optional[int] = None, levels: Optional[int] = None, heads: int = 1, rule: str = 'attention', tau: float = 1.0, kappa: float = 1.0, pad: str = 'reflect', delay_compensation: bool = True, fast_fft: bool = True, pad_tol: float = 1e-08, eps: float = 1e-12)

Undecimated Daubechies tight frame (FFT-batched, any T) with parameter-free gate rules.

Args:
    order:     Daubechies order N (N vanishing moments, support 2N-1).
    support:   alternative to `order`; must be odd (= 2N-1).
    levels:    number of detail levels J (None -> as many as fit T, max 10).
    heads:     channel groups sharing one scale-attention pattern.
    rule:      'attention' | 'shrink' | 'identity'.
    tau:       attention temperature.
    kappa:     energy-smoothing width, in units of each band's dyadic scale.
    pad:       'reflect' (no wrap-around artefacts) or 'circular'.
    delay_compensation: align bands in time (pure phase; keeps PR).
    fast_fft:  extend padded length to a 5-smooth FFT size.
    pad_tol:   reflect padding covers all but this fraction of every band's
               impulse-response energy (PR is exact for any value).
Input/Output: (B, T, C).

num_levels(self, T: int) -> int

Detail levels J used for length T (the `levels` argument, or as many as fit, at most 10).

analysis(self, x: torch.Tensor) -> torch.Tensor

(B, T, C) -> (B, J+1, T, C) band coefficients (on the unpadded grid).

synthesis(self, W: torch.Tensor) -> torch.Tensor

Adjoint of `analysis` in circular mode; (B, J+1, T, C) -> (B, T, C).
(In reflect mode use forward(); W here lives on the unpadded grid.)

gates(self, x: torch.Tensor) -> torch.Tensor

Gate field (B, J+1, T, C) the mixer applies to x (for inspection).

forward(self, x: torch.Tensor) -> torch.Tensor

(B, T, C) -> (B, T, C): analysis, gate rule, synthesis (rule='identity' returns x).
